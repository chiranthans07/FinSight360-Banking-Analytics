# FinSight 360 — Banking Analytics

## 📊 Project Overview

FinSight 360 is an end-to-end banking analytics project designed to simulate the work of a Data Analyst in a financial organization.

The project analyzes customer, account, transaction, fraud, and customer-support data to identify business trends, operational issues, customer behavior, and risk patterns.

## 🎯 Objectives

- Analyze customer and account behavior
- Identify transaction trends and patterns
- Analyze fraud and risk indicators
- Evaluate customer support performance
- Build data-driven dashboards and insights
- Provide actionable business recommendations

## 🛠️ Tools & Technologies

- **MySQL** — Database management and SQL analysis
- **Python** — Data cleaning and exploratory data analysis
- **Tableau** — Interactive data visualization
- **Power BI** — Business intelligence dashboards
- **Excel** — Data analysis and reporting
- **GitHub** — Project documentation and version control

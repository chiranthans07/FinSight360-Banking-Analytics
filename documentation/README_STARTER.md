# FinSight 360 — Banking Operations & Risk Intelligence Platform

Synthetic portfolio project for demonstrating an end-to-end Data Analyst workflow.

## Stack
- MySQL
- Python (Pandas, NumPy, Matplotlib/Seaborn)
- Power BI
- Tableau
- Excel
- Git/GitHub

## Pipeline
Raw CSV → MySQL → SQL Analysis → Python Cleaning/EDA → BI Dashboard → Business Insights

## Dataset
All records are synthetic and created specifically for this portfolio project. No real customer or banking data is used.

## Tables
branches, customers, accounts, transactions, support_tickets, fraud_alerts

# FinSight 360 — Starter Business Questions

1. What is the total transaction value and transaction count?
2. Which customer segments generate the most transaction value?
3. Which branches have the highest transaction volume?
4. What percentage of transactions fail or are reversed?
5. Which transaction types have the highest average transaction value?
6. Which customers have the highest activity?
7. Which issue types generate the most support tickets?
8. Which support categories have the longest resolution time?
9. Which branches have the highest number of risk alerts?
10. Which risk types are most common?
11. What percentage of alerts are High/Critical?
12. Which customers have both high transaction activity and high risk scores?
13. What data-quality problems exist in the raw transaction data?
14. What monthly trends can management observe?
15. What operational or risk areas should management investigate further?
